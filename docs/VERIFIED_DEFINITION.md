# GAFAIG — DEFINITION OF VERIFIED — 2026-04-10

## PURPOSE
Defines what “Verified” means in GAFAIG.

---

## VERIFIED =

A system is VERIFIED when ALL conditions are met:

1. Case exists
2. Scoring completed
3. Decision = APPROVED
4. Registry snapshot published
5. Signed verification exists

---

## PUBLIC SIGNAL

Verified means:
- Independently assessed
- Deterministically scored
- Officially certified
- Publicly recorded

---

## NOT VERIFIED IF:

- No decision
- Decision not approved
- No registry record
- Signature invalid

---

## FINAL RULE

Verified is a SYSTEM STATE, not a label.
