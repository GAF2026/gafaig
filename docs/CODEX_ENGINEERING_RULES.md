# IMPLEMENTATION WORKFLOW

Before modifying code:

1. Review the requested files.

2. Understand the existing implementation pattern.

3. Preserve the existing implementation style.

4. Make the smallest safe change.

5. Avoid unrelated modifications.

After implementation:

1. Verify imports.

2. Verify TypeScript compilation.

3. Verify route consistency.

4. Verify applicant organization scoping.

5. Verify authority-boundary language remains intact.

6. Summarize modified files.
