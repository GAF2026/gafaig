# PUBLICATION RULE

No public observability surface may show data unless it is tied to an explicitly published certification surface.

Public visibility requires:

```sql
PUBLISHED = TRUE
```

or projection from a canonical public view that already enforces explicit publication, such as:

```sql
CORE.V_REGISTRY_PUBLIC
CORE.V_REGISTRY_AI_SYSTEMS_PUBLIC
CORE.V_REGISTRY_STATS_BY_COUNTRY
```

Publication control must remain deterministic.

Publication visibility must remain append-only.

Publication observability must remain cryptographically verifiable.

Publication infrastructure must remain Snowflake-originated.
